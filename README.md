# 火箭发射模拟器（Rocket Launch Simulator）

中国科技馆航天科普互动课件：长征十号运载火箭「发射 → 入轨」全过程模拟。
纯网页实现，**双击 `index.html` 就能玩**，无需安装、无需联网，可离线部署到展厅大屏和触屏一体机。

## 这是什么

- 以**长征十号 + 梦舟载人飞船（深空版）**为构型的发射入轨模拟器
- 从点火、程序转弯、Max-Q、助推/级间分离，到滑行段、三级点火入轨的完整 13 个节点
- 真实物理：确定性积分，时间线可拖回任意时刻精确回放（不是录像，是把物理重新算一遍）
- 面向中小学科普教学与展厅互动设计，附带完整的讲解要点（见 `运行说明.txt`）

## 快速开始

1. 下载本仓库（Code → Download ZIP，或 `git clone`）
2. 双击 `index.html`（推荐 Chrome / Edge）
3. 先点**演示模式**完整看一遍，再切**挑战模式**上手

## 两种模式

| 模式 | 用途 | 特点 |
|---|---|---|
| 演示模式 | 讲台讲解 / 展厅大屏 | 自动飞行、关键节点自动解说与慢放、滑行段自动暂停弹讲解卡、强制浅色画面 |
| 挑战模式 | 学生上手 | 自己控制俯仰/油门/三级关机，深色指控大厅风格，评分 + 10 个成就徽章，新手/标准/硬核三档难度 |

## 操作

- 通用：空格 暂停 · ←→ 拖时间线 · 1/2/3 切镜头 · Tab 数据详略 · R 重开 · H 帮助
- 挑战模式：↑↓ 俯仰 · W/S 油门 · 回车 点火/关机 · X 变速
- 触屏：底部按钮与按键一一对应，触屏一体机可直接用

## 科学准确性

- 内置物理自检脚本，66 项断言全部通过：

  ```bash
  node tests/physics-audit.js
  ```

  覆盖：起飞重量 2187 吨、起飞推力 26250 kN、推重比 1.224、标准大气表、Δv 恒等式残差 < 1e-6 m/s、200 km 圆轨道速度 ≈ 7785 m/s、轨道倾角 19.6°、时间线回放与实时推进完全一致等。
- 箭体比例按公开资料绘制（误差 10% 以内）——「数量级正确」的科普级精度，不是工程图纸。

## 教学亮点

- **滑行段自动暂停**：近地点为负 = 还没入轨，「飞得高 ≠ 入轨」的最佳讲点
- **三级手动关机**（硬核档）：在速度还在增加时果断停手，训练科学判断
- **双目标轨道**：200 km 停泊轨道 vs 400 km 空间站轨道，难度参数分别调校
- **无障碍**：数值旁的形状标识（圆/三角/菱/六边）供色弱学生分辨状态，支持减少动态效果
