## 0. 阅读须知：参数可信度分级

本文档所有数值都带**来源标签**，实现时不得去掉标签：

| 标签 | 含义 | 处理原则 |
|---|---|---|
| **【公开】** | 可在公开资料（官方发布、百科、论文、公开飞行试验报道）查到的值 | 直接使用，不得改动 |
| **【推导】** | 由【公开】值经物理公式严格算出（如由 F 与 Isp 求质量流率） | 直接采用推导结果 |
| **【近似】** | 无公开值，按工程经验/同类型号类比给出的估计 | 集中放在 `vehicle.md` 的"可调参数区"，允许实现时微调并回填本文档 |
| **【游戏】** | 为可玩性/可理解性主动设定的值，物理上不真实但合理 | 必须在代码与 UI 中显式标注，不得伪装成真实数据 |

**硬性要求**：任何在 UI 上显示给玩家的数字，其来源标签必须可查（见 §9 可核验性）。

## 1. 坐标系与单位制

### 1.1 单位制

**内部计算一律使用 SI 基本单位**，仅在渲染层转换显示单位。这是最容易出 bug 的地方，必须先钉死。

| 物理量 | 内部单位 | 显示单位 | 备注 |
|---|---|---|---|
| 长度 / 位置 / 半径 | m | m（<1 km）/ km（≥1 km） | 地球半径用 m 存储 |
| 速度 | m/s | m/s（<1 km/s）/ km/s（≥1 km/s） | |
| 加速度 / 过载 | m/s² | m/s² 或 g（1 g = 9.80665） | 过载显示用 g |
| 质量 | kg | t（1 t = 1000 kg） | 火箭级段用 t 显示 |
| 力 / 推力 | N | kN | |
| 时间 | s | s / mm:ss | 任务时间用 T+xxx s |
| 角度 | **rad** | ° | 配置文件与 UI 用度，读入时转 rad |
| 压力 / 动压 / 压强 | Pa | kPa | 动压用 kPa |
| 密度 | kg/m³ | kg/m³ / 科学计数法 | |
| 温度 | K | K / °C | 大气用 K |
| 比冲 | s | s | 用"秒"制（等效排气速度 = Isp·g0） |

> **实现约定**：常量 `G0 = 9.80665`（标准重力加速度，**仅作单位换算用，不是当地的重力**）。

### 1.2 坐标系：二维地心惯性系（ECI，平面）

**决策：主仿真使用二维平面地心惯性坐标系，不做三维。**

| 项 | 规定 |
|---|---|
| 原点 | 地心 |
| X 轴 | 发射时刻，指向发射点的**正东方向**（在轨道平面内） |
| Y 轴 | 在轨道平面内，由 X 轴逆时针旋转 90°（即指向"天顶偏北"方向） |
| 正方向 | 火箭向东飞，X 增大，Y 增大（远离地心） |
| 惯性性 | 坐标系**不随地球自转**，固定在惯性空间中 |
| 第三维 | 不存在。轨道倾角 i 由球面三角几何单独计算（见 §1.4） |

**为什么用二维而不是三维**：
1. 上升段全过程（东向发射）运动严格落在一个过地心的平面内，二维在物理上是**精确的**，不是简化（忽略 J2 摄动与侧向机动的前提下）。
2. 实现复杂度、数值稳定性、调试成本都大幅下降——这对"无构建工具的纯 JS 单页应用"是决定性优势。
3. 侧视 2D 视图与二维仿真天然对应，视觉与数据不会打架。
4. 三维带来的唯一增量（轨道倾角）可以用一行球面三角公式算出来，**不需要三维仿真**。

**二维近似的适用边界（必须写进代码注释）**：
- 发射方位角固定为 **90°（正东）** 时，本模型精确。
- 若开放方位角 ψ ≠ 90°，则本模型为**近似**：地球自转速度在轨道平面内的分量取 `v_rot·sin ψ`，垂直平面的分量被丢弃（物理上会引起小幅平面外运动，忽略）。此模式标注为【近似】，建议作为 v1.1 可选功能（Should S-07）。
- 忽略：J2 地球扁率摄动、月球/太阳引力、大气升力外的侧向力。这些在 15 分钟上升段内影响量级 < 10 m，对本项目的教学精度无意义。

### 1.3 关键角度定义（必须区分，否则后期必出 bug）

```
              ↑ 天顶方向（r̂，径向单位矢量）
              |
              |    / 推力方向 û_T（姿态角 θ 从当地水平量起）
              |   /
    ──────────┼──/────→ 当地水平方向（t̂，东向单位矢量）
              | /  ↙ 攻角 α
              |/ ↙
              |↙ 速度矢量 v⃗（弹道倾角 γ 从当地水平量起）
              |
              O 地心方向
```

| 符号 | 名称 | 定义 | 取值 |
|---|---|---|---|
| **θ (theta)** | **姿态角 / 俯仰角** | 火箭纵轴（推力方向）与**当地水平**的夹角 | 90° = 垂直向上，0° = 水平 |
| **γ (gamma)** | **弹道倾角** | 速度矢量与**当地水平**的夹角 | 90° = 垂直上升，0° = 水平飞行，负 = 下降 |
| **α (alpha)** | **攻角** | α = θ − γ | 0 = 推力完全沿速度方向 |
| **φ_pos** | 极角 | 位置矢量与 X 轴的夹角 | 仅内部用 |

**三个角的关系：α = θ − γ。攻角是结构与气动载荷的判定量，不是控制量。**

### 1.4 轨道倾角的几何计算（不走仿真）

东向发射（方位角 ψ = 90°）时：

```
cos(i) = cos(φ_lat) · sin(ψ)
```
- ψ = 90° → cos(i) = cos(φ_lat) → **i = φ_lat**
- 文昌 φ_lat ≈ 19.6°N → **i ≈ 19.6°**

若开放方位角（v1.1，S-07），则：
```
cos(i) = cos(φ_lat) · sin(ψ)
v_rot_inplane = ω · R(φ_lat) · cos(φ_lat) · sin(ψ)   ← 作为初速度输入仿真
i 由上式算出，仅用于轨道根数显示
```
标注为【近似】。

## 3. 大气模型

### 3.1 决策

**使用 US Standard Atmosphere 1976 的分层模型，0–86 km 精确分层，86 km 以上指数外推。**

**为什么不用简化的 ρ = ρ₀·exp(−h/H)**：
等温近似在 30 km 以上误差可达 **3–10 倍**，会严重扭曲阻力与动压曲线，直接破坏 P1（物理是真的）。分层模型的实现成本只是多一张 7 行的表，性价比极高。

### 3.2 分层参数表（US76，几何高度）

| 层 | 底高 h_b (km) | 温度递减率 L (K/km) | 底层温度 T_b (K) | 底层气压 p_b (Pa) | 底层密度 ρ_b (kg/m³) |
|---|---|---|---|---|---|
| 0 | 0 | −6.5 | 288.15 | 101325 | 1.2250 |
| 1 | 11 | 0.0 | 216.65 | 22632 | 0.3639 |
| 2 | 20 | +1.0 | 216.65 | 5474.9 | 0.08803 |
| 3 | 32 | +2.8 | 228.65 | 868.02 | 0.01322 |
| 4 | 47 | 0.0 | 270.65 | 110.91 | 0.001427 |
| 5 | 51 | −2.8 | 270.65 | 66.939 | 8.61 × 10⁻⁴ |
| 6 | 71 | −2.0 | 214.65 | 3.9564 | 6.42 × 10⁻⁵ |
| 7 | 84.852 | — | 186.87 | 0.37338 | 6.96 × 10⁻⁶ |

### 3.3 计算公式

对给定高度 h，找到所在层 b，令 Δh = h − h_b，T = T_b + L·Δh：

**气压**
```
若 L ≠ 0:   p = p_b · (T / T_b)^( −g₀·M / (R* · L) )
若 L = 0:   p = p_b · exp( −g₀·M·Δh / (R* · T_b) )
```

**密度**
```
ρ = p · M / (R* · T)
```

**音速**
```
a = sqrt(γ_air · R_air · T)
```
海平面校验：a = sqrt(1.4 × 287.0528 × 288.15) = **340.3 m/s** ✓

### 3.4 86 km 以上处理

```
ρ(h) = ρ(86 km) · exp( −(h − 86000) / H_up ),  H_up = 7000 m   【近似】
p(h) 同理
T(h) = 186.87 K（常数）                                        【近似】
```
- h > 120 km：可置 ρ = 0（此时动压 < 0.3 Pa，对仿真无影响）。
- 说明：US76 在 86 km 以上进入稀薄气体层，分子平均自由程增大，连续介质假设失效，**任何"精确"密度都无物理意义**。本项目在此高度以上的气动力已完全可忽略，用简单外推即可。

### 3.5 实现建议：预计算查表 + 线性插值

为保证浏览器端 60 fps 下可跑 50× 时间加速，建议：

1. 启动时预计算 **0–100 km，每 100 m 一个点**的 `ρ` / `p` / `a` 数组（共 1001 个点，约 24 KB）。
2. 运行时用**线性插值**取中间值，插值误差 < 0.1%。
3. h > 100 km 用 §3.4 指数外推。
4. 提供 `atmo(h)` 的精确分层函数作为查表的**自检基准**（启动时抽查 20 个点，误差 > 1% 则报错）。

## 5. 推进：推力、比冲、质量流率、齐奥尔科夫斯基

### 5.1 基本关系

```
等效排气速度:  v_e = Isp · g₀                 [m/s]
质量流率:      ṁ  = F / (Isp · g₀)            [kg/s]
齐奥尔科夫斯基:  Δv = Isp · g₀ · ln(m₀ / m₁)   [m/s]
```

### 5.2 推力与比冲随高度变化

发动机在海平面因大气压产生过膨胀损失，真空中推力最大。标准线性近似：

```
Isp(h) = Isp_vac − (Isp_vac − Isp_sl) · ( p(h) / p₀ )
F(h)   = F_vac   − (F_vac   − F_sl  ) · ( p(h) / p₀ )
ṁ      = F(h) / ( Isp(h) · g₀ )          ← 注意：ṁ 随高度几乎不变
```

**关键性质**：由于 F 与 Isp 同步变化，**ṁ 在整个飞行过程中近似恒定**。这是重要的自检项：实现后可打印 ṁ(h) 曲线，波动应 < 1%。

以 YF-100K 模块（7 台）为例：

| h (km) | p/p₀ | F (kN) | Isp (s) | ṁ (kg/s) |
|---|---|---|---|---|
| 0 | 1.000 | 8750 | 301.6 | 2957.7 |
| 5 | 0.5332 | 9084 | 313.1 | 2958.4 |
| 11 | 0.2234 | 9587 | 329.1 | 2969.5 |
| 20 | 0.05403 | 9601 | 329.5 | 2969.5 |
| 40 | 0.00274 | 9763 | 336.9 | 2957.0 |
| 70+ | ≈ 0 | 9772 | 337.0 | 2957.0 |

> 波动 0.4%，符合预期 ✓（11–20 km 处的小台阶是层边界插值引起，实现时查表插值会把它抹平）

### 5.3 节流（Throttle）

YF-100 系列公开支持 **65%–105%** 推力调节（【公开】，2026-02-11 低空演示验证飞行试验报道）。

```
F(h, η)   = η · F(h)
Isp(h, η) = Isp(h) · (1 − 0.15 · (1 − η)²)     【近似】节流带来比冲损失
ṁ(h, η)   = F(h, η) / (Isp(h, η) · g₀)
```
- η ∈ [0.65, 1.05]，默认 1.00。
- 比冲损失曲线为【近似】：深度节流时喷管效率下降，二阶衰减是常见的工程拟合。100%→65% 时 Isp 损失约 1.8%。
- **YF-75E（三级）不支持节流**（【游戏】简化假设），η ≡ 1.00。

### 5.4 Δv 的实时累计（重要：不要只用分段火箭方程）

分段火箭方程（§5.1 第三式）只在 Isp 恒定时精确。由于 Isp 随高度变化，且存在节流，**必须用积分形式**：

```
Δv_ideal(t) = ∫₀ᵗ [ F(h, η) / m ] dτ        ← 每步累加 (T/m)·dt
```

分段火箭方程只用作**任务前的静态预算核对**（见 §8）与 UI 上的"理论值"对照。

## 6. 阻力、动压与 Max-Q

### 6.1 动压

```
q = ½ · ρ(h) · v²            [Pa]
v = |v⃗|                     [m/s]，惯性系速度大小
```

### 6.2 阻力

```
D = q · A · Cd(M, α)          [N]
方向: 与 v⃗ 反向
参考面积 A = π · (5.0/2)² = 19.635 m²     【推导】（芯级直径 5 m，【公开】）
```

**阻力系数 Cd（Mach 数相关，工程近似）**

| M | 0.0 | 0.4 | 0.8 | 1.0 | 1.2 | 1.5 | 2.0 | 3.0 | 4.0 | 6.0 | 8.0 | ≥10 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| Cd₀ | 0.30 | 0.31 | 0.38 | 0.60 | 0.56 | 0.50 | 0.42 | 0.33 | 0.28 | 0.24 | 0.21 | 0.19 |

- 跨音速峰值 M≈1.0 处 Cd = 0.60（**音障**的可视化来源）。
- 攻角修正：`Cd = Cd₀(M) + 0.02 · |α_deg|`【近似】，α 单位度。
- Mach 数：`M = v / a(h)`。
- 表内插值用**线性插值**。
- 来源：【近似】。细长体运载火箭的典型 Cd 曲线，形状正确（跨音速峰 + 超音速衰减），绝对值按同类运载火箭类比给出。

### 6.3 法向力（攻角产生的气动转向力）

```
N = q · A · CN_α · α          [N]，α 单位 rad
CN_α = 1.8 /rad               【近似】细长体小攻角法向力系数导数
方向: 垂直于 v⃗，在轨道平面内，使 γ 增大（抬头为正）
```
- 这一项是**重力转弯之外，主动气动转向的物理基础**。没有它，攻角对弹道毫无影响，玩家的 pitch 操作就会"手感发虚"。
- 线性回归范围：|α| < 15°，超出后 N 饱和（用 `N = q·A·CN_α·(15° in rad)·sign(α)` 截断）。

### 6.4 Max-Q

| 项 | 预期值 | 来源 |
|---|---|---|
| 出现时刻 | **T+70 ~ T+90 s** | 【推导】见下 |
| 出现高度 | **12 ~ 16 km** | 【推导】 |
| 动压峰值 | **25 ~ 35 kPa** | 【推导】 |
| 此时速度 | 450 ~ 550 m/s | 【推导】 |

**标定依据**：2026 年 2 月 11 日长征十号系列低空演示验证飞行试验公开报道——"点火起飞约 1 分钟后，在高度约 11 km 处达到最大动压条件"【公开】。
该次飞行使用的是**长征十号甲一级 + 梦舟 + 逃逸塔**的组合（远轻于完整三级半构型），因此加速更快、Max-Q 出现更早更低。完整 CZ-10 构型（GLOW 2187 t，推重比 1.224）的 Max-Q 预期略晚略高，落在上表区间。

**实现要求**：
- Max-Q 必须由**数值积分实测**（记录 q 的历史最大值及其时刻/高度），不得硬编码。
- 若实测 Max-Q 落在 T+70~90 s / 12~16 km / 25~35 kPa 之外 ±20%，说明弹道程序或阻力模型有偏差，需回查。
- 玩家在 Max-Q 前后**主动节流**（η 降至 0.75~0.85）可显著降低峰值动压，这是挑战模式的核心技巧之一。

## 7. 运动方程与重力转弯

### 7.1 状态向量

```
state = { x, y, vx, vy, m, t, θ_att }
```
| 变量 | 含义 | 单位 |
|---|---|---|
| x, y | ECI 平面位置 | m |
| vx, vy | ECI 速度 | m/s |
| m | 当前总质量 | kg |
| t | 任务时间（T+） | s |
| θ_att | 当前姿态角（一阶滞后后的实际值） | rad |

### 7.2 单位矢量构造

```
r     = sqrt(x² + y²)
r̂     = (x/r, y/r)                    径向单位矢量（指向天顶）
t̂     = (−y/r, x/r)                   当地水平东向单位矢量
v     = sqrt(vx² + vy²)
v̂     = (vx/v, vy/v)
γ     = asin( (v⃗ · r̂) / v )           弹道倾角（相对当地水平）
```

### 7.3 受力与加速度

```
(1) 推力:   a⃗_T = (F(h,η)/m) · û_T ，  û_T = cos(θ_att)·t̂ + sin(θ_att)·r̂
(2) 阻力:   a⃗_D = −(D/m) · v̂
(3) 法向力: a⃗_N = (N/m) · n̂ ，  n̂ = 垂直于 v̂、使 γ 增大的方向
                                 n̂ = (−v̂_y, v̂_x)  若该方向与抬头一致
(4) 引力:   a⃗_g = −(μ/r³) · r⃗

总加速度:  a⃗ = a⃗_T + a⃗_D + a⃗_N + a⃗_g
```

**质量变化**：
```
dm/dt = −Σ ṁ_i   （对所有正在工作的级求和）
```

**姿态一阶滞后**（模拟控制系统的响应时间）：
```
dθ_att/dt = (θ_cmd − θ_att) / τ_att ,   τ_att = 0.8 s   【近似】
```
- τ_att 让"操作"不会瞬间生效，产生真实的惯性手感。
- 0.8 s 是运载火箭姿态控制回路的典型响应时间量级。

**攻角**：
```
α = θ_att − γ
```

### 7.4 重力转弯：执行方式（关键设计决策）

#### 决策

> **采用三层制：自动驾驶（AP）执行基准 pitch 程序 → 玩家施加有界偏差（bias）→ 可选全手动。**
> **默认层 = 第 2 层（AP + 玩家偏差修正）。**

#### 理由

| 方案 | 优点 | 致命问题 |
|---|---|---|
| **A. 全程手动 pitch**（KSP 原教旨） | 硬核、自由度最高 | 学习门槛 30+ 分钟；新手前 3 次必然失败；与核心支柱 P3（5 分钟上手）冲突；演示模式无法保证弹道可复现 |
| **B. 纯自动驾驶，玩家只观察** | 演示模式完美 | 挑战模式毫无可玩性，学生变成观众，SDT 的"自主"需求完全落空 |
| **C. AP + 偏差修正（推荐）** | ① 弹道可复现，演示模式有保底；② 玩家有真实控制权与明确归因；③ 学习曲线可控；④ 硬核玩家可切到 A 层 | 需要额外实现 bias 通道与回中逻辑（成本约 30 行代码） |

#### 具体机制

**第 1 层：自动驾驶（AP）基准 pitch 程序**

采用**高度驱动**的指数衰减程序（比时间驱动更鲁棒，因为高度是积分的直接结果，对推力偏差不敏感）：

```
θ_AP(h) = 90° · exp( −c · (h − h₀) )        h ≥ h₀
θ_AP(h) = 90°                                h < h₀
```
| 参数 | 默认 | 说明 |
|---|---|---|
| h₀ | 1 500 m | 转向起始高度。之前保持垂直，穿过低空稠密大气 |
| c | 0.0229 /km | 转向强度。标定使 h = 180 km 时 θ_AP ≈ 1.5° |
| θ_min | 0° | 程序下限，θ_AP 不取负值 |

**程序曲线（默认参数）**

| h (km) | θ_AP (°) | 说明 |
|---|---|---|
| < 1.5 | 90.0 | 垂直上升 |
| 5 | 83.0 | 开始压头 |
| 11 | 74.1 | Max-Q 附近 |
| 20 | 61.0 | |
| 30 | 46.8 | 明显倾斜 |
| 50 | 31.4 | |
| 75 | 17.6 | 一级分离附近 |
| 100 | 9.4 | |
| 150 | 3.0 | 二级末 |
| 180 | 1.5 | 三级点火时近似水平 |

**可调参数（挑战模式进阶）**：`h₀`（1.0–3.0 km）与 `c`（0.018–0.030 /km）。这两个参数就是"重力转弯"这一知识点在游戏里的操作化表达——调 h₀ 是"什么时候开始倒"，调 c 是"倒得多快"。

**第 2 层：玩家偏差（bias）— 默认层**

```
θ_cmd = clamp( θ_AP(h) + bias , 0° , 95° )
bias ∈ [ −15° , +15° ]
输入: ↑/W = bias +3°/s ； ↓/S = bias −3°/s
```

| 机制 | 参数 | 说明 |
|---|---|---|
| 输入速率 | 3 °/s | 按住 5 s 打满 |
| AP 回中 | `bias(t+dt) = bias(t) · exp(−dt/τ_bias)` | 松开按键后自动缓慢回正 |
| τ_bias | 入门档 6 s / 标准档 10 s / 硬核档 ∞（不回中） | 难度档位的主要调节旋钮 |
| 硬限幅 | \|α\| ≤ 8°（q > 10 kPa 时） | 超限即判定结构解体 |

**为什么需要回中**：没有回中，玩家一个失误的 bias 会累积成不可挽回的偏轨，导致"我不知道自己错在哪"（胜任感受损）。有回中，失误会自愈，玩家可以专注在**时机**而不是**手感**上——这更符合科普教学的目标，也更符合硬核物理（真实火箭的制导回路本来就是在不断纠偏）。

**第 3 层：全手动（挑战模式 · 硬核档 / 成就「手动飞行」）**

```
AP 关闭，bias 失效
玩家直接控制 θ_cmd： ↑/W = θ_cmd +2°/s ， ↓/S = θ_cmd −2°/s
无回中、无下限保护
```
- 此模式下**不降低任何物理精度**，只是去掉辅助。
- 解锁成就「手动飞行：在关闭自动驾驶的情况下完成入轨」。

#### 演示模式的姿态处理

演示模式**强制第 1 层（纯 AP）**，禁用玩家输入。原因：教师大屏讲解时，任何误触都会毁掉一节课的演示。教师若想展示"手动操作的影响"，可临时切到挑战模式的自由飞行（不计时、不评分）。

## 8. 数值积分方案

### 8.1 积分器

**推荐：固定步长四阶龙格-库塔（RK4）。**

| 备选 | 评价 |
|---|---|
| **RK4（推荐）** | 精度 O(dt⁴)，实现 20 行，无历史依赖（可从任意状态重启，利于"节点重开"），速度足够 |
| 半隐式欧拉 | 精度 O(dt)，长时间滑行段能量漂移明显，**不推荐** |
| Velocity Verlet | 对保守力系优，但本系统有推力和阻力（非保守），优势丧失 |
| RK45 / 自适应步长 | 精度更好，但步长变化会让"时间加速"的每帧步数不可预测，且与"固定物理步长"的事件检测耦合复杂。**不推荐 v1.0** |

### 8.2 步长

采用**分区固定步长**（不是自适应，保证可预测性）：

| 飞行阶段 | 判据 | 步长 dt | 理由 |
|---|---|---|---|
| 大气段 | h < 100 km 且 q > 100 Pa | **0.02 s** | 大气密度梯度大，需要细步长捕捉 Max-Q |
| 真空段 | 其他 | **0.25 s** | 二体问题，RK4 @0.25 s 精度达 1e-9 量级 |
| 滑行段 | 发动机关机 | **0.5 s** | 纯二体，可用大步长（可选优化） |

**切换滞环**：从大气段切真空段用 `h > 105 km` 上行阈值、`h < 95 km` 下行阈值，避免边界抖动。

### 8.3 稳定性分析（自检用）

RK4 的稳定域约为 `|λ·dt| < 2.8`。本系统的最快特征根：

| 来源 | 特征时间 | λ_max (s⁻¹) | dt 上限 |
|---|---|---|---|
| 姿态一阶滞后 τ_att = 0.8 s | 0.8 s | 1.25 | 2.24 s |
| 大气密度梯度（v/H） | 8500/1000 = 8.5 s | 0.118 | 23.8 s |
| 二体轨道（近地周期 84 min） | 5060 s | 2.0e-4 | 1.4e4 s |

→ 最严约束 dt < 2.24 s。**选取的 0.02 / 0.25 / 0.5 s 有 4–100 倍裕度，绝对稳定。** ✓

### 8.4 时间加速与渲染解耦

```
每渲染帧（目标 16.67 ms / 60 fps）：
    sim_time_to_advance = W × frame_dt
    N_steps = ceil( sim_time_to_advance / dt )
    for i in 1..N_steps:  rk4_step(dt)
```

| 加速档 W | 大气段 (dt=0.02) 每帧步数 | 真空段 (dt=0.25) 每帧步数 |
|---|---|---|
| 1× | 1 | 1 |
| 2× | 2 | 1 |
| 5× | 4 | 1 |
| 10× | 9 | 1 |
| 25× | 21 | 2 |
| 50× | 42 | 4 |

**性能保护**：
- 单帧步数上限 `N_max = 200`。若 `N_steps > N_max`，自动降低加速档并在 HUD 提示"性能受限，已降至 W×"。
- 帧时间超过 25 ms 连续 10 帧 → 自动降一档。
- 建议用 `requestAnimationFrame` + 累加器（accumulator）模式，避免"掉帧→追帧→更掉帧"的死亡螺旋。

### 8.5 事件检测（必须做，否则会漏掉分离节点）

物理步长是离散的，事件（推进剂耗尽、达到高度、动压超限）会落在两步之间。**必须用线性插值求精确时刻**：

```
以"推进剂耗尽"为例：
    若 prop(t) > 0 且 prop(t+dt) ≤ 0：
        过零时刻: t* = t + dt · prop(t) / ( prop(t) − prop(t+dt) )
        用 (t* − t) 作为最后一步的步长，重新积分到 t*
        在 t* 触发分离/关机事件
        用 dt − (t* − t) 完成本帧剩余步进
```

**需要事件检测的量**：
1. 各级推进剂耗尽（→ 关机 / 分离）
2. 逃逸塔分离高度、抛整流罩高度（→ 分离）
3. 动压超阈值、攻角超阈值（→ 失败判定）
4. 目标入轨条件满足（→ 三级关机）
5. 高度 < 0（→ 撞地失败）

### 8.6 数值精度自检（实现时必须内置）

| 检查项 | 判据 | 触发 |
|---|---|---|
| 真空段能量守恒 | `|Δ(ε)| / |ε| < 1e-6`（ε = v²/2 − μ/r），发动机关机期间 | 每 10 s 抽查，超限写 console.warn |
| ṁ 恒定性 | `max(ṁ)/min(ṁ) < 1.02`（同一级、无节流时） | 每级分离时检查 |
| 质量守恒 | `Σ(各级消耗) == 初始总重 − 当前总重` | 每帧，误差 > 1 kg 报错 |
| Δv 恒等式（§9.1） | 残差 < 1 m/s | 每帧 |
| RK4 步长收敛性 | 用 dt/2 跑 60 s，末位置差 < 10 m | 启动时自检一次 |

## 9. 可核验性：玩家怎么验证"这是真的"

这是核心支柱 P1 的落地。**没有可核验性，硬核物理就只是策划的自说自话。**

### 9.1 Δv 恒等式（最重要的一条）

在二维平面、ECI 惯性系下，以下恒等式**必须实时成立**：

```
v_current = Δv_ideal − Δv_gravity − Δv_drag − Δv_steering + v_rot
```

| 项 | 计算方式 | 说明 |
|---|---|---|
| `v_current` | `sqrt(vx² + vy²)` | 当前惯性系速度（HUD 主数据） |
| `Δv_ideal` | `∫ (F/m) dt`，每步累加 | 火箭自己提供的总速度增量 |
| `Δv_gravity` | `∫ (μ/r² − v_h²/r) · sin γ dt` | 重力损失。`v_h = v·cos γ`（水平分量）。注意减去离心力项 |
| `Δv_drag` | `∫ (D/m) dt` | 阻力损失 |
| `Δv_steering` | `∫ (F/m)(1 − cos α) dt + ∫ (D_extra/m) dt` | 转向损失 = 推力方向偏离速度方向的余弦损失 + 攻角引起的附加阻力 |
| `v_rot` | 常数 438.1 m/s | 地球自转赠送的速度（**不是火箭提供的**） |

**实现要求**：
- 每帧计算残差 `residual = v_current − (Δv_ideal − Δv_gravity − Δv_drag − Δv_steering + v_rot)`。
- **`|residual|` 必须 < 1 m/s**。若超出，说明方程或符号有误。
- **残差要在 UI 上显示**（放在"数据核验"面板里，默认折叠）。这是"我们没作弊"的最强证据——把一个可以证明自己没作弊的数字直接摆在玩家面前。

> **给教师的讲解话术**："看这个数——残差 0.3 米每秒。意思是，屏幕上的速度，是用火箭方程一步步积分算出来的，不是我写死的动画。你改任何一个参数，所有数字都会跟着变。"

### 9.1.1 分段火箭方程的边界规则（静态 Δv 表与实时积分对账的前提）

`vehicle.md` §4.2 的静态 Δv 表，与运行时 `∫(F/m)dt` 的积分值必须对得上（工程容差 1%）。**唯一常见的对不上原因，是分段边界取错。**

**规则（硬性）**：

```
Δv_table 的分段边界集合  ==  抛除事件时刻集合  ∪  发动机工况变化时刻集合
```

即：**任何一个分段内部，质量变化只能来自推进剂消耗，不能来自抛除。**

**为什么**：抛除事件本身**不产生 Δv**（被抛物体以零排气速度离开，不提供冲量），它只能通过降低后续段的起始质量间接获益。若把抛除事件"埋"在某一段内部、直接用 `Isp·g₀·ln(m_start/m_end)` 算，等价于假设被抛掉的质量是**当作推进剂烧掉的**，会系统性高估 Δv。

**本项目的实例（逃逸塔，量级 37 m/s）**：

```
错误：329 × 9.80665 × ln(2187.0 / 618.1)            = 4077 m/s
正确：329 × 9.80665 × ln(2187.0 / 678.6)            = 3776 m/s   (T+0→170，塔在箭上)
    + 337 × 9.80665 × ln( 669.6 / 618.1)            =  264 m/s   (T+170→175.8，塔已抛)
                                                      ────
                                                      4040 m/s
```

**用于自检**：若静态表与实时积分对不上，先查分段边界，再查 Isp 取值。详见 `vehicle.md` §4.2.1 与验收项 V-15 / V-16。

### 9.2 实时 Δv 预算表（HUD 元素）

| 行 | 内容 | 单位 |
|---|---|---|
| 理论总 Δv（推进剂全部耗尽） | `Σ Isp·g₀·ln(m₀/m₁)`，各级分别列出 | m/s |
| 已消耗 Δv（理想） | `Δv_ideal` | m/s |
| − 重力损失 | `Δv_gravity` | m/s |
| − 阻力损失 | `Δv_drag` | m/s |
| − 转向损失 | `Δv_steering` | m/s |
| ＋ 地球自转补偿 | `v_rot` = 438.1 | m/s |
| **＝ 当前速度** | `v_current` | m/s |
| 入轨所需速度（目标轨道） | `sqrt(μ/r_target)` ≈ **7785**（200 km）/ **7669**（400 km） | m/s |
| **剩余 Δv 余量** | `Δv_ideal_remaining − (v_target − v_current) − 预计剩余损失` | m/s |
| 核验残差 | `residual` | m/s |

> **这里的 7785 / 7669 是本模拟器的实现值**，参考球取 **R_REF = 6377.3 km**
> （`C.SITE.R0`，文昌发射点地心距）。公开资料常引的 7786 是取整值、
> 严格按 `R_E = 6371 km` 手算是 7788.5——三者差 3.5 m/s（0.05%），只是参考球
> 半径不同，不是谁算错了。**讲解与 UI 一律用 7785**，完整口径说明见
> `vehicle.md` §4.1「口径注 A」。实测输出见 `tests/physics-audit.js`。

**"剩余 Δv 余量"是挑战模式的核心张力来源**——它把"我还能不能入轨"变成一个实时可读的数字。

### 9.3 轨道根数实时反算

从 `(r⃗, v⃗)` 每帧（或每 10 帧）反算：

```
ε     = v²/2 − μ/r                        比机械能
a     = −μ / (2ε)                         半长轴
e⃗     = ((v² − μ/r)·r⃗ − (r⃗·v⃗)·v⃗) / μ     偏心率矢量
e     = |e⃗|
r_p   = a(1 − e)                          近地点半径
r_a   = a(1 + e)                          远地点半径
h_p   = r_p − R_E                         近地点高度
h_a   = r_a − R_E                         远地点高度
T_orbit = 2π·sqrt(a³/μ)                   轨道周期
i     = 19.6°（几何值，见 §1.4）
```

**HUD 显示**：a、e、h_p（近地点高度）、h_a（远地点高度）、T、i。

**自检**：`r_p + r_a = 2a`，误差应 < 1 m。

**教学高光时刻**：**近地点高度 h_p 从负值爬升到 0 以上的那一刻**。
- h_p < 0 意味着"这个椭圆的近地点在地表以下"→ 会掉回来 → 还没入轨。
- h_p > 0（且 > ~100 km，考虑残余大气）→ 真正入轨。
- 建议 UI 在 h_p 穿过 0 时做一次高亮动画，并在演示模式自动暂停讲解。这是 K4 知识点（入轨 = 横向速度够快）的最佳可视化。

## 11. 失败判定的物理量（详细阈值见 `mission-profile.md` §4）
