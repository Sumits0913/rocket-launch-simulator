## 0. 剖面总览

**任务目标**：用长征十号将梦舟载人飞船（深空版，26 t）送入 **200 km 圆轨道**，轨道倾角 19.6°（从文昌东向发射）。

### E3｜最大动压 Max-Q（T+70~90 s）★ 任务最高潮

| 项 | 内容 |
|---|---|
| **触发** | 数值积分实测 `q` 的峰值（**不硬编码**） |
| **物理** | `q = ½ρv²`。速度在涨、密度在跌，两者乘积先涨后跌，存在峰值。预期 h ≈ 12–16 km，v ≈ 450–550 m/s，q ≈ 25–35 kPa |
| **玩家操作** | 挑战模式：**主动节流至 75%~85%**。这是全任务唯一需要"抢时机"的操作 |
| **演示讲解** | "速度在增加，空气在变稀薄，两者的乘积——动压——先涨后跌。这个峰值叫 Max-Q，是箭体结构受力最恶劣的时刻。真实火箭会在这里**主动降低推力**。" |
| **UI 表现** | 动压曲线高亮峰值点；HUD 动压读数变黄（>20 kPa）/变红（>35 kPa） |
| **教学点** | **K2**（大气阻力先增后减，存在最大动压点） |
| **预警机制** | 挑战模式在 `q` 达到预测峰值 80% 时（约 T+65 s）弹出提示："即将进入最大动压区，建议降低推力" |

## 3. 入轨判据与评级

### 3.1 判据

| 结果 | 判据 | 说明 |
|---|---|---|
| **完美入轨** | `h_p ≥ 195 km` 且 `h_a ≤ 215 km` | 偏心率 e ≤ 0.0015 |
| **成功入轨** | `h_p ≥ 180 km` 且 `h_a ≤ 240 km` | 偏心率 e ≤ 0.0046 |
| **勉强入轨（软失败）** | `h_p ≥ 100 km`（近地点在大气层外，短时间内不会再入） | 给分但不给"成功"评价 |
| **亚轨道（失败）** | `h_p < 100 km` 且三级推进剂耗尽 | 会再入大气 |
| **坠毁（失败）** | 见 §4 | |

**参考值**：200 km 圆轨道，r = 6571 km。
- h_p = 180 km → r_p = 6551 km
- h_a = 220 km → r_a = 6591 km
- e = (6591 − 6551)/(6591 + 6551) = 40/13142 = **0.00304** ✓

### 3.2 演示模式的保证

演示模式**必须**达成"成功入轨"或更好。保障措施：
1. 使用标定好的默认 pitch 程序（physics.md §7.4）
2. 三级自动关机，判据为"成功入轨"区间的**中值**（目标 h_p = 200 km，h_a = 210 km）
3. 若因浮点误差/标定偏差导致未达标，**不判定失败**，而是：
   - 自动延长三级工作时间至达标（最多消耗到 35 t）
   - 若仍不达标，显示"演示数据偏差"提示并记录日志（供开发者排查），但播放流程继续
4. 演示模式**禁用所有失败判定**（F1–F5 全部关闭）

> 理由：教师在大屏前讲解时，最坏的结果是"演示失败"。物理精度可以在挑战模式和"数据核验"面板里体现，演示模式的第一优先级是**稳定可复现**。

## 5. 失败反馈规范

**原则：失败反馈必须给出"为什么"和"下次怎么做"，不能只说"任务失败"。**

### 5.1 反馈三层结构

| 层 | 内容 | 载体 |
|---|---|---|
| **L1 即时** | 失败瞬间：画面定格 → 解体/坠毁动画（≤2 s）→ 半透明遮罩 | 视觉 |
| **L2 归因** | 失败类型 + 关键数值 + **一句提示**（见 §4.1 表格） | 中央卡片 |
| **L3 复盘** | 失败时刻的完整状态快照 + 该时刻前后 30 s 的曲线回放 + 关联知识卡 | 侧栏面板 |

### 5.2 重来机制（关键：低惩罚）

| 选项 | 行为 |
|---|---|
| **从上一节点重来** | 回滚到最近一个事件节点（如 E5 助推分离）的状态快照，玩家从那里继续。**默认选项** |
| **从点火重来** | 完整重跑 |
| **观看演示** | 切换到演示模式，看一遍正确做法（AI 接管飞行） |

**快照机制**：在每个事件节点（E0–E12）保存完整状态 `{x, y, vx, vy, m, t, θ_att, 各级推进剂}`。回滚 = 恢复快照 + 清空该节点之后的累计量（Δv 累加器、损失累加器需可回滚）。

> **实现要求**：`state` 必须是纯数据对象，不含闭包/引用，否则快照回滚会失败。这是 `physics.md` §7.1 状态向量设计的直接原因。

### 5.3 失败统计（用于难度自适应）

记录每次失败的类型与节点。若同一玩家：
- **连续 2 次在同类型失败** → 自动放宽该判据 20%，并弹出对应知识卡
- **连续 3 次失败** → 提示"要不要切换到入门难度？"（不强制）
