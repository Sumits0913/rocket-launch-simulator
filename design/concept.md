# 火箭发射模拟器 · 游戏概念文档

> 项目代号：Launch Sim
> 版本：v1.0（概念基线）
> 撰写：策划负责人（文策渊）
> 范围：独立新作，**仅覆盖「发射 → 入轨」阶段**，与《中国载人登月任务互动课堂 V4》物理隔离

---

## 0. 一句话定义

> 一款**基于真实物理的网页版长征十号发射模拟器**：学生操控（或旁观）一枚长征十号运载火箭，从文昌点火起飞，经历真实的大气、重力、动压与多级分离，把梦舟载人飞船送进 200 km 近地轨道——全程数据可核验、可与真实任务对照。

## 1. 核心支柱（3 条）

一切设计取舍回到这三条。冲突时，优先级自上而下。

| # | 支柱 | 含义 | 可验证的判据 | 反面（我们不做什么） |
|---|---|---|---|---|
| **P1** | **物理是真的** | 屏幕上每个数字都由公式算出来，不是脚本演的动画 | 玩家可随时调出 Δv 预算表，逐项核对：理想 Δv − 重力损失 − 阻力损失 = 当前速度；轨道根数反算的远/近地点与实时状态自洽 | 不做"能量条 / 血条"式的伪物理；不做"按方向键火箭就转弯"的 arcade 手感 |
| **P2** | **一次发射讲得完** | 单次完整流程（点火→入轨）在 **12–18 分钟**内结束，且**随时可暂停、可跳节点、可回放** | 教师用演示模式讲完一遍的时间 ≤ 20 分钟（含讲解停顿） | 不做 KSP 式的建造 / 长期经营；不做需要反复重试才能看到结局的长流程 |
| **P3** | **两种人都能用** | 教师（几乎不操作）与学生（独立操作）在同一套物理内核上跑两条不同动线 | 教师 0 培训即可开演示；学生 5 分钟内完成首次成功入轨（见 §6） | 不做"一套 UI 两种人凑合用"；不做只有硬核玩家才看得懂的纯数据界面 |

**支柱之间的冲突处理原则**：
- P1 vs P2 → 物理精度不退让，但用**时间加速**和**节点跳转**解决时长问题，而不是简化物理。
- P1 vs P3 → 物理不退让，但**把物理的复杂度藏在"自动驾驶 + 偏差修正"后面**（详见 `gdd/physics.md` §6 重力转弯方案）。
- P2 vs P3 → 时长不退让（演示模式必须可控），但给挑战模式提供"快速重来"与"从任意节点重开"。

## 2. MDA 框架分析

### 2.1 Mechanics（机制）——系统做什么

| 机制层 | 内容 | 状态 |
|---|---|---|
| **M1 推进与质量流** | 多级火箭、真实比冲、质量流率、推进剂消耗、齐奥尔科夫斯基 Δv | Must |
| **M2 环境** | 分层大气（US76）、随高度衰减的重力、地球自转初速 | Must |
| **M3 气动** | 阻力、动压 q、Max-Q、跨音速阻力峰值 | Must |
| **M4 姿态与制导** | 重力转弯（gravity turn）、pitch 程序、偏航修正 | Must |
| **M5 时序与分离** | 逃逸塔分离、助推分离、一二级分离、抛整流罩、二三级分离、船箭分离 | Must |
| **M6 轨道力学** | 位置/速度 → 轨道根数（a/e/i/近远地点/周期）实时反算 | Must |
| **M7 失败判定** | 动压超限解体、攻角超限、推进剂耗尽、再入、结构过载 | Must |
| **M8 双模式控制层** | 演示模式脚本引擎 / 挑战模式引导与评分 | Must |
| **M9 时间控制** | 暂停 / 慢放 / 时间加速（1×–50×）/ 节点跳转 | Should |
| **M10 成就与评分** | 入轨精度、Δv 效率、Max-Q 控制、手动飞行 | Should |
| **M11 参数可视化** | 实时曲线（速度/高度/动压/加速度）、Δv 预算条、推进剂条 | Should |

### 2.2 Dynamics（动态）——运行时产生什么

| 动态 | 描述 | 设计意图 |
|---|---|---|
| **D1 推力/质量比的时间赛跑** | 火箭越飞越轻，加速度单调上升（一级末可达 3–4 g）。玩家必须在一级关机前主动节流，否则过载伤结构 | 制造第一个"必须做决策"的时刻 |
| **D2 Max-Q 的窗口压力** | T+55–75 s 动压冲顶（真实数据：约 T+60 s / h≈11 km）。此时转向太快→攻角大→横向载荷；不节流→结构载荷大 | 制造全任务最紧张的高潮点，且**它是可预测的**，成就感来自"我提前准备好了" |
| **D3 重力转弯的单行道** | 转向过早→重力损失剧增、燃料耗尽；转向过晚→冲得太高、横向速度不足、再入 | 核心难度来源。教师最爱讲的一段，因为它反直觉 |
| **D4 分离节点的节奏脉冲** | 每次分离：质量骤降、加速度跳变、推力重配。视觉与数值同时"抖一下" | 天然的讲解节拍器，演示模式的分段依据 |
| **D5 余量焦虑** | 推进剂条持续下降，Δv 剩余量与"还需多少"实时对比 | 心流的主要张力源；解决方式是"提前规划"而非"手速" |
| **D6 轨道成型的收束感** | 三级点火后，近地点高度从负值一路爬到正数，轨道根数逐渐收敛 | 收尾的正反馈：从"在飞"到"在轨"的质变瞬间 |

### 2.3 Aesthetics（美学）——希望玩家获得什么体验

按 MDA 八种美学分类，本项目主攻三项：

| 主攻 | 美学类型 | 在本项目中的体现 |
|---|---|---|
| ★★★ | **1. 感官（Sensation）** | 尾焰、音爆云、Max-Q 时的画面震动、分离时的火光与镜头切换、大屏上的速度数字跳动。**演示模式的首要卖点**——科技馆大屏的第一吸引力 |
| ★★★ | **4. 挑战（Challenge）** | 把"入轨"这件事做成可度量、可复现、可超越的目标：入轨精度 ±km、Δv 效率 %、入轨用时。**挑战模式的首要卖点** |
| ★★ | **8. 发现（Discovery）** | "原来火箭是这么转弯的""原来动压会先涨后跌""原来一级分离时速度才 3.7 km/s"。**科普价值的核心**——学生自己发现规律，比听讲记得牢 |

辅助：
- **3. 叙事（Narrative）**：弱叙事但强"任务感"。用真实任务语言（"助推分离""抛整流罩""船箭分离""入轨"）构建航天工程师的角色代入，不编故事、不设虚构角色。
- **7. 提交（Submission）**：作为"消遣"的低强度模式——演示模式的自动播放，适合展区循环播放。

**明确不做的美学**：竞争（Competition，无多人、无排行榜对抗）、幻想（Fantasy，不虚构外星/科幻设定）、表达（Expression，无自定义涂装/建造）。

## 3. 玩家心理学定位

### 3.1 自我决定论（SDT）：三大基本需求如何满足

| 需求 | 定义 | 本项目的满足方式 | 反面风险（要避免） |
|---|---|---|---|
| **自主 Autonomy** | 我感到是自己在选择 | ① 挑战模式提供 2–3 个真实可调决策（转向时机、节流时机、三级点火时长），而非几十个旋钮；② 允许关闭自动驾驶完全手动；③ 允许失败重来且不惩罚 | 面板上堆 50 个参数 → 选择过载，反而失去自主感 |
| **胜任 Competence** | 我感到自己在变强 | ① 反馈即时且**归因明确**（"偏航 3°"而不是"失败"）；② 难度分档，每档目标清晰可达；③ 成就按"理解程度"而非"通关次数"设计（如"你能说出为什么 Max-Q 后要节流吗"） | 失败只给一个"任务失败"弹窗 |
| **关联 Relatedness** | 我与他人/更大事物相连 | ① 演示模式的师生共看、教师讲解互动；② 挑战模式的"本次飞行数据 vs 真实长征十号任务数据"对照；③ 结尾展示"你刚刚完成了一次与真实航天工程师相同的 Δv 预算工作" | 纯单机、与真实工程无关的架空设定 |

### 3.2 心流曲线（Flow Channel）

目标：把单次 12–18 分钟的任务切成 6 段，每段有明确的难度峰谷，避免长时间平淡或长时间高压。

```
难度
 │                    ●  D2 Max-Q
 │              ▲         ▲  D3 转向窗口
 │     ▲       ╱ ╲       ╱ ╲
 │    ╱ ╲     ╱   ╲     ╱   ╲        ▲  D6 三级点火与圆化
 │   ╱   ╲   ╱     ╲   ╱     ╲      ╱ ╲
 │  ╱     ╲ ╱       ╲ ╱       ╲    ╱   ╲___
 │ ╱       V         V         ╲__╱        ╲___ 入轨确认
 │╱  点火           一级分离   滑行
 └──────────────────────────────────────────────► 时间
  T+0   T+60   T+173  T+230  T+449  T+570  T+720
         60s    173s   230s   449s   570s   720s
  起飞   Max-Q  助推   一级   二级   三级    入轨
                分离   分离   关机   关机
```

| 段 | 时间窗 | 玩家认知负荷 | 设计手法 |
|---|---|---|---|
| S1 点火起飞 | T+0 → T+50 | 低（观赏） | 镜头、音效、数字跳动；只要求玩家观察"加速度怎么越来越快" |
| S2 Max-Q 峰 | T+50 → T+90 | **高（峰值）** | 唯一需要节流决策的窗口；挑战模式提前 10 s 预警 |
| S3 一级后段 | T+90 → T+230 | 中 | 转向窗口持续，但自动驾驶托底；观察推进剂与过载 |
| S4 二级段 | T+230 → T+449 | 低–中 | 大气已稀薄，主要看速度逼近 7.8 km/s；抛整流罩是视觉小高潮 |
| S5 滑行段 | T+449 → T+570 | **低（谷值，刻意留白）** | 演示模式的核心讲解窗口：教师在此讲轨道力学；挑战模式可 10× 加速跳过 |
| S6 三级入轨 | T+570 → T+720 | **高（第二峰）** | 最后一次点火，窗口有限（地球在转、远地点在逼近）；入轨瞬间是全局最高正反馈 |

**心流保障机制**：
- **动态难度**：挑战模式下，若玩家连续 2 次在同一点失败，自动放宽该点容差 20%，并弹出对应知识卡（不降低物理精度，只放宽判定阈值）。
- **可中断性**：任何时刻可暂停，暂停时数据面板冻结、可展开查看公式。**这一点对科技馆场景是硬需求**——老师随时会被打断提问。
- **无惩罚重来**：失败后一键"从此节点重开"，不清空已解锁的知识卡与成就。

### 3.3 Bartle 玩家类型：主打哪类

| Bartle 类型 | 本项目适配度 | 说明 |
|---|---|---|
| **成就者 Achiever** | ★★★ **主打** | 挑战模式的评分、精度、效率、成就徽章，直接对位。"入轨精度 ±2 km""Δv 效率 96%"是可量化的成就 |
| **探索者 Explorer** | ★★ 次打 | 参数可视化层：学生调出大气密度曲线、阻力曲线、Δv 预算表，自己发现"为什么动压先涨后跌"。演示模式的"数据层开关"服务于此 |
| **社交者 Socializer** | ★ 弱 | 不建多人系统。但通过"教师讲解 + 全班共看 + 分享本次飞行数据"满足轻量关联需求 |
| **杀手 Killer** | ✗ 不做 | 无 PvP、无排行榜对抗 |

**用户画像（本项目实际使用者）**：

| 角色 | 典型场景 | 核心诉求 | 对应模式 |
|---|---|---|---|
| 科技馆辅导员（用户本人） | 大屏前带 20–40 名学生，边播边讲 | 不翻车、能暂停、能跳到重点、数据可信 | 演示模式 |

## 5. 视觉锚点（供美术负责人接手）

> 以下 5 条是"感觉基准"，不是最终画面描述。美术负责人在此基础上出视觉方案。

### 锚点 1｜**工程蓝图的冷静感**
- **关键词**：深空底色、细网格、单色描边、等宽数字。
- **为什么**：这是"仪器"不是"游戏"。玩家要相信屏幕上的数字是真的，界面就不能太娱乐化。
- **参考感觉**：任务控制台 / 飞行遥测屏 / 工程图纸，而不是卡牌游戏 / 赛博朋克。
- **反面**：霓虹渐变、大量发光、卡通描边、拟物化按钮。

### 锚点 2｜**侧视剖面是主视图**
- **关键词**：2D 侧视、火箭占屏幕高度 60–70%、地球弧线在底部、星空在上。
- **为什么**：重力转弯、高度、弹道倾角这些核心概念，只有侧视图能一眼看懂。俯视图/3D 反而讲不清。
- **要求**：整个任务过程中，火箭**始终可见且朝向正确**（随 pitch 角旋转），玩家能直观看到"它正在慢慢倒下来"。

### 锚点 3｜**数字要大，且要"跳"**
- **关键词**：主数据（速度 / 高度）字号 ≥ 大屏观看距离的 1/30；数字滚动有过渡动画而非硬切。
- **为什么**：大屏场景，最后排学生要能看清；数字跳动本身是"感官美学"的主要来源。
- **量化基准**：1080p 投影下，主速度数字 ≥ 64 px 等宽；次要数据 ≥ 32 px；参考 `ui-spec.md` §1.3。

### 锚点 4｜**尾焰是唯一的暖色**
- **关键词**：整体冷色（深蓝/青灰），只有尾焰、分离火光、警告是暖色（橙/黄/红）。
- **为什么**：用颜色引导注意力。冷色 = 背景与数据，暖色 = 能量与危险。
- **要求**：尾焰长度/亮度随推力与大气密度变化（高空真空中尾焰膨胀变大变淡），这是物理正确性的一个可视化窗口。

### 锚点 5｜**分离瞬间必须有"事件感"**
- **关键词**：镜头轻推、白闪、碎屑/气体扩散、HUD 上对应节点高亮 + 中文事件名（"助推分离"）。
- **为什么**：7 个分离节点是讲解的天然节拍器，必须让学生"记住这一刻"。
- **要求**：演示模式下分离瞬间建议**自动降速到 0.25× 并停留 1.5 s**，给教师留出讲解窗口（可在设置里关掉）。

### 交付给美术的补充约束
| 约束 | 说明 |
|---|---|
| 技术栈 | 纯 SVG / Canvas 2D，无 3D、无外部素材库、无网络请求 |
| 分辨率基准 | 1920×1080 为主基准，需能放大到 2560×1440 与投影 1024×768 不破版 |
| 动画原则 | 所有视觉动画**由物理状态驱动**，不做无物理含义的装饰动画 |
| 素材量控制 | 火箭 4 个构型（完整 / 无助推 / 无一级 / 无二级）+ 尾焰 3 档 + 分离特效 1 套 + 背景 3 层（地面/大气/星空） |

## 6. 与目标用户的对接：科普价值的落点

用户（科技馆辅导员）的核心诉求是**教学可交付**，不是游戏好玩度。因此明确本项目的 5 个科普知识点，每个知识点都必须在界面上有对应的可视化承载：

| # | 知识点 | 界面承载 | 学生能自己发现的现象 |
|---|---|---|---|
| K1 | 火箭靠"扔掉质量"加速（齐奥尔科夫斯基） | Δv 预算条 + 分级质量条 | 分离瞬间加速度跳变、Δv 剩余量变化 |
| K2 | 大气阻力先增后减，存在最大动压点 | 动压实时曲线 + Max-Q 标记 | 速度在涨，动压却先涨后跌 |
| K3 | 火箭不是"往上飞"，是"往侧面加速"（重力转弯） | 侧视弹道轨迹 + 速度矢量箭头 | 高度只有 200 km，但速度有 7.8 km/s |
| K4 | 入轨 = 横向速度够快，掉不下来 | 轨道根数面板 + 近地点高度从负转正 | 近地点爬过 0 的那一刻 |
| K5 | 分级是为了甩掉死重 | 分级 Δv 贡献占比图 | 一级只贡献全箭满载总 Δv（12 272 m/s）的约 43%，却占了 85% 的起飞质量 |

**成功判据（给用户的验收标准）**：一名初中生在无人指导的挑战模式下，能在 3 次尝试内成功入轨，并在结束后正确回答 K1–K5 中的至少 3 个。
