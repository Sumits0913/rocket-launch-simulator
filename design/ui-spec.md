# UX 规格文档

> 项目：火箭发射模拟器（Launch Sim）
> 版本：v1.0
> 上游依赖：`concept.md`（视觉锚点）、`modes.md`（HUD 元素清单）
> 分工：**本文档负责结构、布局、流程、可读性规范；色彩/字体/图形风格由美术负责人（art-director）在 `design/art/` 下定义。**

---

## 0. 设计前提

| 约束 | 影响 |
|---|---|
| **科技馆大屏 / 教室投影** | 观看距离 3–10 m，元素必须够大、够清楚 |
| **用户为非技术岗** | 无命令行、无配置、双击 `index.html` 即用 |
| **教师边播边讲** | 任何时刻可暂停；无模态弹窗打断 |
| **学生首次接触硬核模拟** | 5 分钟内必须完成首次成功入轨 |
| **无构建工具、纯前端** | 布局用 CSS Grid/Flex，不依赖任何 UI 框架 |
| **1920×1080 为主基准** | 需向下兼容 1024×768（老旧投影），向上支持 2560×1440 |

| ④b | 右侧栏 | 340 × 720（可折叠） | Δv 预算、轨道根数、曲线、核验面板 | L2/L3 | `Tab` 切换 |

**主视图区必须占屏幕面积 ≥ 40%。** 它是感官美学（concept.md §2.3）的载体，不能被数据挤扁。

### 1.3 大屏可读性规范（硬性）

#### 字号分级（1920×1080 基准，其他分辨率按比例缩放）

| 级别 | 用途 | 字号 | 字重 | 示例 |
|---|---|---|---|---|
| **XL** | 主数据（速度、高度） | **64 px** | 700 | `7.83 km/s` |
| **L1** | 事件名、字幕、讲解 | 40–48 px | 600 | `助推分离` |
| **L2** | 次要数据、提示条 | 32 px | 500 | `下一步：降低推力` |
| **L3** | 面板标题、单位标签 | 28 px | 500 | `Δv 预算` |
| **L4** | 面板内数据、表格 | 24 px | 400 | `重力损失 1530 m/s` |
| **L5** | 核验信息、脚注 | 20 px | 400 | `来源：公开` |

**数字必须用等宽字体（tabular-nums）**，防止跳动的数字导致布局抖动。

#### 观看距离换算

| 观看距离 | 最小可辨字号 | 本项目对应级别 | 支持的分辨率 |
|---|---|---|---|
| 3 m（教室前排） | 18 px @1080p | L5 | 全部 |
| 6 m（教室中排） | 32 px @1080p | L2 | 全部 |
| 10 m（科技馆大屏） | 48 px @1080p | L1 | 需 ≥ 1080p |

**结论**：L1 以下（L2–L5）的内容在 10 m 外看不清，属正常——它们是"教师/玩家近看"的层级。**必须保证 L1 与 XL 的内容在 10 m 外清晰可辨**，即：速度、高度、事件名、字幕四项。

#### 对比度与元素尺寸

| 项 | 要求 |
|---|---|
| 文字对比度 | ≥ 4.5:1（WCAG AA）；主数据 ≥ 7:1（AAA） |
| 关键数据描边 | 主数据加 2 px 深色描边或半透明背板，保证在任何背景（含明亮尾焰）上可读 |
| 可点击元素 | 最小 48 × 48 px（触屏场景 64 × 64 px） |
| 进度条/数据条 | 高度 ≥ 16 px；分段标记宽度 ≥ 4 px |
| 曲线线宽 | ≥ 2 px；网格线 1 px 且对比度低于数据线 |
| 告警色 | 不得仅靠颜色区分，必须同时配图标或文字（色盲友好） |

#### 布局弹性

| 分辨率 | 处理 |
|---|---|
| ≥ 2560×1440 | 等比放大，右侧栏可常驻展开 |
| 1920×1080 | **基准布局** |
| 1366×768 | 右侧栏默认折叠；主视图区占比 ≥ 45% |
| 1024×768 | 右侧栏默认隐藏（仅按钮唤出层叠）；底部条精简为图标 |

**实现**：用 CSS `clamp()` + `vw/vh` 单位做字号弹性，避免硬编码 px。

## 2. 关键交互流程

### 2.1 流程 A：教师使用演示模式

```
打开 index.html
    ↓
【首屏】模式选择页（2 个大卡片：演示模式 / 挑战模式）
    ↓  点击「演示模式」
【演示准备页】
    · 数据层选择（L0/L1/L2/L3，默认 L1）
    · 起点选择（从头开始 / 从某节点开始，默认从头）
    · 「开始演示」按钮
    ↓
【演示播放】
    · 自动播放，E0 点火
    · 教师随时：空格暂停、←→跳节点、↑↓调速、D 切数据层
    · E3/E5/E6/E8/E10/E11 自动降速（可在设置关闭）
    · E9 滑行段自动暂停，弹出讲解引导浮层
    ↓
【E12 船箭分离】
    ↓
【结束页】本次飞行数据总结卡 + 「重新演示」/「返回首页」
```

**首屏设计要点**：
- 只有 2 个大卡片，无其他干扰元素。**教师不应在首屏做任何超过 3 秒的决策。**
- 卡片上直接写明适用对象：「演示模式 — 教师讲解用」「挑战模式 — 学生上手用」
- 右下角小字：`按 F11 全屏`

### 2.2 流程 B：学生使用挑战模式

```
打开 index.html
    ↓
【首屏】模式选择页
    ↓  点击「挑战模式」
【难度选择页】
    · 三档卡片（入门 / 标准 / 硬核），标注各自特点
    · 默认选中「标准」
    ↓  点击「开始」
【飞行前引导】（首次进入显示，可跳过）
    · 3 张卡片，每张一个知识点（见 §3.2）
    · 耗时 ≤ 40 秒
    ↓
【发射台】
    · 提示「按 空格 点火」
    ↓
【飞行中】
    · T+0–30 s：观察期（无操作）
    · T+30 s：解锁 bias 输入
    · T+65 s：Max-Q 预警 → 节流
    · T+448.4 s：滑行段（可 10× 加速）
    · T+571.4 s：三级点火
    · T+804.1 s：三级关机 → 入轨
    ↓
【结算页】
    · 评级 + 四项得分 + 成就解锁 + 数据总结
    · 「再来一次」/「挑战更高难度」/「返回首页」
```

### 2.3 流程 C：失败后的重来

```
失败发生
    ↓
【失败画面】（≤2 s 动画）
    ↓
【失败卡片】（居中，非全屏遮罩）
    · 失败类型 + 关键数值 + 一句提示
    · 三个按钮：
        [从上一节点重来]  ← 默认，高亮
        [从头再来]
        [看一遍演示]
    ↓
【复盘面板】（可选展开，点击「为什么？」）
    · 失败时刻状态快照
    · 前后 30 s 的曲线回放
    · 关联知识卡
```

**失败卡片不得使用全屏模态遮罩**——大屏场景下会让下面的学生完全看不到内容。使用**居中卡片 + 半透明背景虚化**，尺寸约 720 × 480。

## 3. 引导与教学：硬核模拟如何做到"5 分钟上手"

### 3.1 5 分钟时间预算

| 时段 | 内容 | 学生做了几个决策 |
|---|---|---|
| 0:00–0:20 | 首屏 → 选挑战模式 → 选标准难度 | 2（都是点一下） |
| 0:20–1:00 | 飞行前引导（3 张卡片，可跳过） | 1（跳过与否） |
| 1:00–1:40 | 点火 + 起飞 + 观察期（1×，无操作） | 1（点火） |
| 1:40–2:20 | 转弯段，可用 bias 微调（4× 加速） | 1–3（bias） |
| 2:20–2:40 | **Max-Q 节流**（唯一需要抢时机的操作） | 1（节流） |
| 2:40–3:40 | 一级/二级段（10× 加速） | 0–1（恢复推力） |
| 3:40–4:10 | 滑行段（可 25× 加速） | 1（三级点火） |
| 4:10–5:00 | 三级段 → 入轨 | 1（三级关机） |

**结论**：全程只有 **2 个必备决策**（Max-Q 节流、三级关机），其余都是可选微调。这就是"5 分钟上手"的实现路径——**不是简化物理，而是减少决策点**。

### 3.2 飞行前引导（3 张卡片）

> 每张卡片 ≤ 15 秒读完。可跳过，跳过入口在卡片右下角常驻。

| # | 标题 | 内容 | 配图 |
|---|---|---|---|
| **卡 1** | **你的目标不是高度，是速度** | "入轨需要的不是飞得高，是飞得**快**——每秒 7.8 公里。到了这个速度，地球就'追不上'你了。" | 侧视示意图：高度 200 km vs 地球半径 6371 km（视觉震撼：200 km 只是地球表面的一层皮） |
| **卡 2** | **火箭要倒过来飞** | "起飞后火箭会慢慢'倒'下来，把推力从'往上'变成'往侧面'。这叫重力转弯——不这么做，重力会白吃掉你 1.5 公里每秒的速度。" | 弹道曲线 + 两个箭头（向上 / 向侧面） |
| **卡 3** | **你只需要做两件事** | "① 在最大动压区（T+70–90 秒）**降低推力**，保护箭体。<br>② 在三级点火后，盯着轨道根数，**速度够了就关机**。<br>别的交给自动驾驶。" | 键位图（Q/E 节流，空格 关机） |

**设计意图**：这 3 张卡片把 K3（往侧面加速）、K4（速度够快才不掉下来）、基础操作讲完。学生即使后面什么都不懂，也能打完一局。

### 3.3 渐进式信息暴露

| 阶段 | 显示的 HUD 元素 | 新增元素 |
|---|---|---|
| 点火–起飞 | 时间、速度、高度、推进剂 | — |
| 转弯段 | + 弹道倾角 γ、姿态指示器 | 姿态概念 |
| Max-Q | + 动压（高亮）+ 告警条 | 动压概念 |
| 一级分离 | + Δv 预算面板（自动展开一次） | Δv 概念 |
| 二级段 | + 加速度 | 过载概念 |
| 滑行段 | **+ 轨道根数面板（强制展开）** | 轨道概念 |
| 三级段 | + 全部 | — |

**原则**：**每引入一个新数据，必须同时给出一句解释。** 首次出现时在该元素旁弹出一个小提示气泡（3 s 后自动消失），例如：
- 动压首次出现："动压 = 空气撞你的力。太大会把火箭撕碎。"
- 轨道根数首次出现："近地点是负的？说明它还会掉回来。"

### 3.4 知识卡系统（Should，S-02）

| 触发 | 知识卡 |
|---|---|
| 首次出现动压 | K2 · 什么是 Max-Q |
| 首次助推分离 | K1 · 为什么要分级 |
| 首次进入转弯段 | K3 · 什么是重力转弯 |
| 首次滑行段 | K4 · 什么才算入轨 |
| 失败：动压超限 | K2 详解 + 节流技巧 |
| 失败：推进剂耗尽 | K3 详解 + 转向时机 |
| 三级点火时 | 比冲 vs 推力：为什么上面级用氢氧 |

知识卡在飞行中**以侧栏滑入形式出现，不打断飞行**；也可在暂停时主动查看。

## 4. 空状态 / 失败 / 成功反馈

### 4.1 空状态

| 场景 | 表现 | 要求 |
|---|---|---|
| **首屏（未选择模式）** | 2 个大卡片 + 一行说明 | 3 秒内可做决策 |
| **发射台（未点火）** | 火箭静态图 + "按 空格 点火" 呼吸提示 | 提示必须闪烁/呼吸，避免学生不知道要按键 |
| **右侧栏折叠** | 一个纵向标签条（"Δv 预算" / "轨道根数"） | 点击展开 |
| **无历史成绩（挑战模式）** | 难度卡片上显示"尚未尝试" | 不显示 0 分 |
| **无成就** | 结算页成就区显示"完成首次入轨解锁成就" | 用占位卡，不是空白 |

### 4.2 加载与初始化

| 场景 | 表现 |
|---|---|
| 页面加载（< 1 s，无外部依赖） | 全屏深色背景 + 一行"正在初始化物理引擎…"；进度体现在预计算大气表（1001 点） |
| 大气表预计算 | 与主视图渲染并行，不阻塞交互 |

### 4.3 失败反馈

**详见 `mission-profile.md` §5。** 本节的补充规范：

| 项 | 规范 |
|---|---|
| 呈现形式 | 居中卡片（720 × 480）+ 背景虚化，**非全屏模态** |
| 动画时长 | 失败动画 ≤ 2 s |
| 卡片内容 | ① 失败类型（大字）② 关键数值 ③ 提示（一句话）④ 三个按钮 ⑤ "为什么？"展开复盘 |
| 文案语气 | 中性、信息性，不嘲讽。用"火箭解体"而非"你失败了" |
| 归因 | **必须指向一个可操作的改进**（"试试更早开始转弯"） |
| 重来成本 | 默认"从上一节点重来"，一键 |

**按钮优先级**：`[从上一节点重来]`（主按钮，高亮）> `[从头再来]`（次）> `[看一遍演示]`（文字链）

### 4.4 成功反馈

| 阶段 | 表现 |
|---|---|
| **入轨瞬间**（近地点穿过 0） | 近地点数字高亮 + 由红转绿；轨道俯视图从不闭合椭圆变为闭合圆；主视图火箭进入"在轨"状态（无尾焰、缓慢自转） |
| **船箭分离** | 相机跟随飞船缓慢拉远；星空背景占比增大 |
| **结算页** | 见下表 |

**结算页内容**：

| 区块 | 内容 |
|---|---|
| **评级**（大） | S / A / B / C / D + 称号（如"A · 优秀航天工程师"） |
| **四项得分**（条形图） | 入轨精度 40 / Δv 效率 30 / Max-Q 控制 15 / 过载控制 15 |
| **本次飞行数据** | 入轨时刻、近/远地点高度、偏心率、周期、倾角、三级消耗、动压峰值、最大过载 |
| **与真实任务对比**（Should S-03） | 本模拟器值 vs CZ-10 公开值（起飞质量/推力/燃烧时间/入轨速度） |
| **成就解锁** | 本次解锁的成就卡片（有动画） |
| **操作按钮** | `[再来一次]` `[挑战更高难度]` `[返回首页]` |

**成功反馈原则**：
- **先给正反馈，再给分数。** 评级动画 0.8 s 后，分数才逐项滑入。
- **"成功入轨"本身永远是绿色正面的。** 低分用"还有优化空间"表述，不用"差"。
- **不强制观看动画**，任何时刻可点击跳过。

### 4.5 反馈的听觉层（Should，S-05）

| 事件 | 音效 |
|---|---|
| 点火 | 低频轰鸣渐强 |
| 发动机噪声 | 持续，音量/音调随推力与大气密度变化（真空中变闷） |
| Max-Q | 轻微气流噪声 + 画面微震 |
| 分离 | 短促爆响 + 白闪 |
| 音爆（跨音速） | 一次性低频"砰" |
| 入轨 | 上行音阶（0.8 s） |
| 失败 | 下行低音（不刺耳，不吓人） |

**音量默认 60%，可一键静音（HUD 常驻喇叭图标）。** 科技馆场景必须能快速静音。

## 5. 可访问性与健壮性

| 项 | 要求 |
|---|---|
| 键盘可达 | 所有功能有键盘快捷键（`modes.md` §3） |
| 色盲友好 | 告警同时用图标 + 文字 + 颜色三重编码 |
| 减少动效 | 尊重 `prefers-reduced-motion`：关闭粒子与震动，保留必要状态变化 |
| 无网络依赖 | 全部资源内联或同目录；**不得有任何外部 CDN / 字体 / 图片请求** |
| 无 localStorage 时 | 降级为"本次会话有效"，不报错 |
| 窗口缩放 | 响应式，不出现横向滚动条 |
| 异常兜底 | 物理数值出现 NaN/Inf 时，立即暂停并提示"数值异常，已暂停"，提供"回到上一节点" |

## 7. 验收清单

- [ ] 1920×1080 下主视图区占屏 ≥ 40%
- [ ] 1024×768 下不出现横向滚动条，右侧栏可唤出
- [ ] 主数据（速度/高度/事件名/字幕）在 10 m 外清晰可辨
- [ ] 所有文字对比度 ≥ 4.5:1，主数据 ≥ 7:1
- [ ] 数字使用等宽字体，跳动不引起布局位移
- [ ] 可点击元素 ≥ 48×48 px
- [ ] 首屏决策时间 ≤ 3 秒（只有 2 个卡片）
- [ ] 失败反馈非全屏模态，且给出可操作的改进建议
- [ ] 成功反馈先正反馈后分数，动画可跳过
- [ ] 全流程无网络请求、无外部依赖
- [ ] 所有键盘功能有鼠标/触屏对应
- [ ] `prefers-reduced-motion` 生效
- [ ] 静音按钮常驻且一键生效
- [ ] NaN/Inf 异常有兜底提示
