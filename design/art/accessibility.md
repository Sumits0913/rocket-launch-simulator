> 本文件定义**可访问性的达标线**，是验收依据，不是建议。

## 1. 分档定义与本项目选择

### 1.1 三档定义

| 档位 | 包含特性 | 适用对象 |
|---|---|---|
| **Basic** | WCAG 2.1 AA 对比度 ｜ 键盘可达 ｜ 语义 HTML 结构 ｜ 图片替代文本 | 通用网页底线 |
| **Standard** | Basic + 色盲友好（非颜色冗余编码）+ 动效敏感开关 + 字号缩放 + 信息密度控制 + 强化焦点可见性 + 大屏可读性 | **本项目必达基线** |
| **Comprehensive** | Standard + 完整屏幕阅读器支持（ARIA live region）+ 全键盘操作游戏 + 高对比模式 + 可调 UI 缩放 + 简化模式（认知负荷管理）+ 术语解释浮层 | 无障碍专业产品 |

### 1.2 本项目选型结论

> **必达：Standard 全档。选做：Comprehensive 中的 4 项。**

**为什么是 Standard 而不是 Comprehensive 全档：**

实时物理模拟游戏的数值每秒变化数十次。若做 Comprehensive 级的完整屏幕阅读器支持（所有数值实时播报），会产生**听觉灾难**——用户听到的将是一串无意义的高速数字流。这不是无障碍，是噪音。

因此本项目的策略是：**视觉通道做满（Standard 全档），听觉通道做"事件级"而非"数值级"（Comprehensive 选做第 1 项）。**

### 1.3 选做的 4 项 Comprehensive 特性

| # | 特性 | 规格 | 优先级 |
|---|---|---|---|
| **C1** | **关键事件 ARIA 播报** | 仅对**离散事件**做 `aria-live="polite"`：阶段变化、分离事件、告警/危险触发、成就解锁、入轨成功。**实时数值不播报。** | **P0** |
| **C2** | **高对比主题** | 第三套主题变量（见 `art-bible.md` 3.4），快捷键 `H` 切换，覆盖全部主题 | **P0** |
| **C3** | **UI 缩放三档** | 100% / 125% / 150%，快捷键 `+` / `−`，与自动缩放相乘 | **P0** |
| **C4** | **术语解释浮层** | 演示模式下鼠标悬停或键盘聚焦专业术语（Δv、动压、节流、程序转弯、卡门线…），显示 22 px 释义卡 | P1 |

**明确不做（Comprehensive 中排除）：**

| 排除项 | 理由 |
|---|---|
| 实时数值的完整 SR 支持 | 每秒变化数十次，播报无意义且造成听觉灾难。改为**按需朗读**（快捷键触发，见 5.4） |
| 全键盘"驾驶"火箭（用键盘完成完整配平与姿态控制） | 面向科普教学，非专业模拟训练；已有节流/分级/暂停等核心键盘操作，满足可达性要求 |
| 简化模式（认知负荷管理） | 演示模式本身即是引导式分步讲解，已承担该功能 |

## 2. 色盲友好（Color Vision Deficiency）

### 2.1 现实约束

| 类型 | 中文名 | 发生率（中国男性 / 女性） | 感知特征 |
|---|---|---|---|
| Deuteranomaly / Deuteranopia | 绿色弱 / 绿色盲 | 约 **5–6%** / 约 0.4% | 绿→偏黄褐，红绿难分 |
| Protanomaly / Protanopia | 红色弱 / 红色盲 | 约 **1.0%** / 约 0.02% | 红→变暗偏黄，红绿难分 |
| Tritanopia | 蓝黄色盲 | < 0.01% | 蓝→绿，黄→粉 |
| Achromatopsia | 全色盲 | 极罕见 | 仅感知明度 |

**教学场景换算**：一个 30 人的班级（男女各半），期望有 **约 1 名男生存在红绿色觉障碍**。这不是边缘案例，是**每堂课都会发生**的必然情况。

### 2.2 色彩策略

**策略一句话：标称色改用青绿以避开"红-绿"轴；严重度改用"形状边数"编码而非仅靠颜色。**

#### 决策 1：标称色用青绿，不用纯绿

纯绿 `#16A34A` 与红 `#DC2626` 在红绿色盲下明度接近、极易混淆。改用**青绿 `#0D9488`**（浅色主题）/ `#2DD4BF`（深色主题），被感知为偏蓝，与红橙在蓝-黄轴上分离，色觉障碍者可稳定分辨。

#### 决策 2：严重度用形状边数递增（核心编码）

**这是本项目最重要的可访问性决策。**

| 语义 | 形状 | 边数 | 图标尺寸（1080p） | 内部符号 | 固定文字标签 |
|---|---|---|---|---|---|
| 标称 / 成功 | **实心圆** | ∞（0 角） | 24 px | 对勾 | 「正常」「成功」 |
| 注意 | **三角形**（正三角，尖角朝上） | **3 边** | 28 px | 感叹号 | 「注意」 |
| 告警 | **菱形**（正方形转 45°） | **4 边** | 32 px | 感叹号 | 「告警」 |
| 危险 | **八角形** | **8 边** | 36 px | 叉 | 「危险」 |
| 未激活 / 中性 | 空心圆（1 px 描边） | — | 24 px | 无 | — |

**编码逻辑**：**形状边数递增 = 严重度递增；图标尺寸递增 = 严重度递增。** 双重形体编码，与色觉、与明度完全无关。

> **为什么形状比颜色更可靠**：在科技馆大屏 / 教室投影场景下，颜色会因投影色偏、环境光、屏幕老化而失真；**形状轮廓不会**。远距观看时，学生先辨识的是形状。因此形状是**主编码**，颜色是**辅助编码**——这与常见的"颜色为主、形状为辅"做法相反，是本场景的刻意选择。

#### 决策 3：明度分析（诚实结论）

我们实测了语义色去饱和后的相对亮度 L：

| 语义 | 浅色主题图形色 | L（相对亮度） | 浅色主题文字色 | L |
|---|---|---|---|---|
| 标称 | `#0D9488` | **0.0897** | `#0B524B` | 0.0666 |
| 注意 | `#F59E0B` | **0.4389** | `#6B4500` | 0.0744 |
| 告警 | `#EA580C` | **0.2459** | `#9A3412` | 0.0937 |
| 危险 | `#DC2626` | **0.1676** | `#8E1414` | 0.0628 |

**诚实结论：这个序列的明度并非单调递增（0.090 → 0.439 → 0.246 → 0.168），且文字色明度全部落在 0.06–0.09 的窄区间内。**

也就是说：**仅靠明度无法区分严重程度**（尤其在全色盲下）。红色系与橙色系在明度上天然接近，这是物理事实，无法通过选色绕过。

**因此：形状编码（决策 2）与文字标签在本项目中是【强制】而非【可选】。** 任何一处语义状态若只用了颜色，即为不达标。

### 2.3 强制规则

| # | 规则 | 验收方式 |
|---|---|---|
| A1 | **任何状态必须 ≥2 重编码**：颜色 + 形状 / 文字 / 位置 至少各一 | 逐元素人工检查 |
| A2 | 语义图标尺寸按严重度递增（24 / 28 / 32 / 36 px） | 检查 CSS |
| A3 | 严重状态的位置优先级更高：危险 → 视觉焦点区；注意 → 次级区 | 布局检查 |
| A4 | **不提供"色盲模式"开关**——默认设计即色盲友好。加开关等于把责任推给用户，且会给色觉障碍学生贴标签 | 无此项功能即为达标 |
| A5 | 图表（Q/G 曲线、Δv 条）中多序列的区分**必须同时用线型**（实线 / 虚线 / 点线），不能只靠颜色 | 检查 `ORB_CURVES` |
| A6 | 量条的分段着色（如 Q 的 0–25 / 25–35 / 35–40 kPa）**必须配分段刻度线 + 阈值文字标注** | 检查 `HUD_Q` |

### 2.4 验收：色盲模拟检查清单

实现完成后，必须用以下 4 种滤镜对**每一个主要界面**截图检查，确认所有状态仍可区分：

- [ ] Deuteranopia（绿色盲，最常见）
- [ ] Protanopia（红色盲）
- [ ] Tritanopia（蓝黄色盲）
- [ ] Achromatopsia（全色盲 / 灰度）

**判定标准**：在任一滤镜下，学生仍能通过形状 + 文字判断当前是"正常 / 注意 / 告警 / 危险"。**若某一滤镜下无法判断，则该处不达标。**

## 3. 大屏可读性

### 3.1 基准场景

| 参数 | 值 |
|---|---|
| 投影幕 | 120 吋 16:9（宽 2.657 m × 高 1.494 m） |
| 分辨率 | 1920 × 1080 |
| 单像素物理尺寸 | 2.657 / 1920 = **1.385 mm** |
| 设计观看距离 | **3 – 10 m**（教室前排到后排 / 科技馆走近与远观） |
| 环境照度 | 100 – 300 lux（非全黑教室） |

### 3.2 字号推导（这是 18 px 下限的来源）

基于人眼视角的最小可辨字高（Snellen 20/20 视力 = 5 弧分可辨，舒适阅读取 2.5–3 倍余量）：

```
最小可辨字高(mm) = 距离(mm) × tan(5 arcmin)  ≈ 距离(mm) × 0.001454
舒适阅读字高(mm) = 最小可辨 × 3
对应 px = 字高(mm) / 1.385
```

| 观看距离 | 最小可辨字高 | **舒适阅读字高** | **对应 px @120吋** | 中文 ×1.2 修正后 |
|---|---|---|---|---|
| 3 m | 4.4 mm | 13.1 mm | 9.5 px | **11.4 px** |
| **6 m** | 8.7 mm | **26.2 mm** | **18.9 px** | **22.7 px** |
| 8 m | 11.6 mm | 34.9 mm | 25.2 px | **30.2 px** |
| 10 m | 14.5 mm | 43.7 mm | 31.5 px | **37.8 px** |

**结论与规则：**

| # | 规则 |
|---|---|
| B1 | **绝对下限 18 px**——仅适用于**拉丁字母与数字的静态内容**（mono 字体，笔画简单：单位、角标、时间戳、图例）。会逐帧变化的数值最小 **20 px** 且字重 ≥600 |
| B2 | **中文下限 20 px**，舒适正文 **22 px**（中文笔画密度高于拉丁字母，需 ×1.2 修正） |
| B3 | 8–10 m 远距场景通过 **UI 缩放 125% / 150%** 档覆盖：22 px × 1.5 = 33 px，满足 8 m；标题 36 × 1.5 = 54 px |
| B4 | 演示模式默认建议 **125% 缩放**（覆盖 6–8 m 主流教室），提供 100/125/150 三档供教师现场调 |

### 3.3 字重与排印

| # | 规则 | 理由 |
|---|---|---|
| B5 | **禁止 200 / 300 细字重**；中文最小字重 400 | 中文笔画在投影下细字重会糊掉，远看消失 |
| B6 | 数值 600，标题与警示 700 | 投影泛白时需要更粗的笔画保住可读性 |
| B7 | **中文字号比同场景拉丁文大 1–2 px** | 中文无升部降部，视觉尺寸偏小 |
| B8 | 中文正文行高 **1.7**（英文常用 1.5） | 中文视觉密度高，需更大行距 |
| B9 | 数字仪表行高 1.0–1.2 | 仪表为紧凑排版 |
| B10 | 所有数字启用 `font-variant-numeric: tabular-nums` | 防止逐帧变化时字宽跳动导致 HUD 抖动 |

### 3.4 对比度（投影环境修正）

| # | 规则 |
|---|---|
| B11 | **所有正文与数据文字的标称对比度目标 ≥ 7:1（AAA）**，而非 AA 的 4.5:1 |
| B12 | 仅 ≥36 px 粗体标题可放宽至 4.5:1 |
| B13 | 对比度 ≤3:1 的颜色组合**只允许用于装饰**（网格、分隔线、禁用态），不得承载任何需要读懂的信息 |
| B14 | 可辨识的控件/面板边框（非装饰）对比度 ≥ 3:1 → 使用 `--c-border-strong #7C8896`（3.24:1），**不使用** `--c-border #D3DAE2`（1.27:1） |

**为什么目标是 7:1 而不是 4.5:1**：教室投影非全黑（100–300 lux），黑位被环境光抬高后有效对比度衰减至标称的 30–50%。以深色主题次文字为例：`#94A6B8` on `#0B1220` 标称 7.52:1，黑位抬至 `#3A3A3A` 后降至 **3.40:1**（不达标）。**这也是演示模式强制浅色主题的量化依据**（详见 `art-bible.md` 3.5）。

### 3.5 信息密度上限

| # | 规则 | 依据 |
|---|---|---|
| B15 | 同一视图内数据组 **≤ 7 个** | 米勒定律 7±2 |
| B16 | 每个数据组内数值 **≤ 3 个** | 降低单组认知负荷 |
| B17 | HUD 区总文字量 **≤ 200 个中文字符** | 大屏远距扫读上限 |
| B18 | 讲解浮层正文 **≤ 3 行**（22 px × 1.7 行高 ≈ 112 px），总量 ≤ 120 中文字符 | 一屏读完，避免翻页打断讲解 |
| B19 | 单个数值的字符数 **≤ 8 字符**（含单位另计） | 例如 `1,842.3` |
| B20 | 界面元素最小间距 **≥ 16 px**（1080p），最小可点击区域 **≥ 48 × 48 px** | 大屏触控 / 远距辨识 |

## 4. 动效敏感

### 4.1 三档开关

| 档位 | 触发方式 | 关闭项 | 保留项 |
|---|---|---|---|
| **完整** | 默认 | — | 全部 |
| **精简** | `prefers-reduced-motion: reduce` **自动命中**，或手动选择 / 快捷键 `M` | 尾焰扰动、粒子、相机阻尼（改瞬移）、面板入场位移（改纯淡入 120 ms）、数字 tween（改跳变）、成就弹跳、视差层（合并为 1 层） | 颜色过渡、进度填充、告警提示（改静态描边 + 图标，不闪烁） |
| **关闭** | 手动选择 | 上述全部 + 所有淡入淡出 | 仅状态色瞬变、进度条瞬变 |

**首次启动行为**：读取 `prefers-reduced-motion`，若为 `reduce` 则自动进入"精简"并弹出**一次性提示**（可改回完整）。设置项在演示模式控制条与挑战模式设置面板均常驻可见。

### 4.2 前庭安全（晕动症）硬阈值

| # | 限制项 | 硬阈值 |
|---|---|---|
| C1 | 全屏平移 / 旋转 / 缩放动效 | **禁止**（相机除外） |
| C2 | 相机缩放变化率 | ≤ 0.5× / 秒 |
| C3 | 相机平移速度 | ≤ 屏幕宽 30% / 秒 |
| C4 | 屏幕震动（撞击反馈） | 单次 150 ms，幅度 ≤ 屏幕 2%，频率 ≤ 2 Hz，**仅 1 次不循环** |
| C5 | 背景视差层位移差 | ≤ 1.5×，层数 ≤ 2 |
| C6 | 尾焰扰动振幅 | ≤ 0.06 × 焰长（见 `asset-spec.md` 3.1） |
| C7 | 粒子数量自适应 | < 50 fps 减半，< 35 fps 关闭 |

### 4.3 光敏癫痫安全

| # | 限制项 | 硬阈值 | 依据 |
|---|---|---|---|
| C8 | 任何闪烁频率 | **≤ 3 Hz** | WCAG 2.3.1 |
| C9 | 全屏高对比闪烁面积 | **≤ 屏幕 25%** | WCAG 2.3.1 |
| C10 | 告警闪烁 | **2 Hz × 3 次后转常亮**，禁止无限循环 | — |
| C11 | 爆炸 / 失败效果 | 禁止 > 25% 面积的白闪；用边框闪红（≤25% 面积）+ 八角形图标替代 | — |
| C12 | 成就解锁动效 | 1 次 120 ms 弹跳，禁止反复弹跳 | — |

### 4.4 数值显示稳定性（投影可读性）

| # | 规则 | 理由 |
|---|---|---|
| C13 | 数值更新用 **300 ms tween**，禁止每帧硬跳 | 每帧跳变的数字在投影下会闪烁成一片 |
| C14 | HUD 数值 HUD 刷新率限制在 **≤ 10 Hz** | 60 Hz 刷新的数字人眼无法阅读，且加剧闪烁 |
| C15 | 固定小数位与千分位分隔符 | 防止字宽变化导致 HUD 布局抖动 |
| C16 | 减少动效档下 tween 改跳变（保留 C14 的刷新率限制） | 换掉了"平滑"但保住了"不闪" |

## 5. 键盘可达性与焦点可见性

### 5.1 快捷键表

| 键 | 功能 | 模式 |
|---|---|---|
| `Space` | 点火 / 暂停 | 双模式 |
| `Enter` | 分级 / 下一阶段 / 讲解浮层「继续」 | 双模式 |
| `↑` `↓` | 节流 ±5% | 挑战模式 |
| `←` `→` | 讲解浮层翻页 / 事件时间线跳转 | 演示模式 |
| `1` – `5` | 视角切换（全景 / 箭体 / 塔架 / 轨道 / 地球） | 双模式 |
| `Esc` | 暂停菜单 / 关闭浮层 / 跳过动画 | 双模式 |
| `Tab` / `Shift+Tab` | 焦点循环 | 双模式 |
| `F1` 或 `?` | 帮助与术语表 | 双模式 |
| `M` | 动效档位循环（完整 → 精简 → 关闭） | 双模式 |
| `H` | 高对比主题切换 | 双模式 |
| `+` / `−` | UI 缩放档位（100 / 125 / 150%） | 双模式 |
| `V` | **按需朗读当前 HUD 数值**（供屏幕阅读器用户） | 双模式 |
| `R` | 复位 | 双模式 |

### 5.2 焦点管理

| # | 规则 |
|---|---|
| D1 | **Tab 序列只包含可交互元素**：按钮、滑块、浮层的翻页/关闭、设置项、时间线节点（演示模式） |
| D2 | **HUD 只读数值默认 `tabindex="-1"`，不进入 Tab 序列**——几十个无意义的焦点会毁掉键盘体验 |
| D3 | 打开浮层/弹窗时实施**焦点陷阱**（focus trap），焦点在该容器内循环；`Esc` 返回并恢复原焦点 |
| D4 | 焦点顺序遵循**视觉顺序**（左→右，上→下），禁止焦点跳到屏幕另一端 |
| D5 | 焦点元素设置 `scroll-margin: 24px`，保证在滚动/缩放容器内始终可见 |
| D6 | 关闭容器后焦点**必须回到触发它的元素**，不允许焦点丢失到 `<body>` |
| D7 | 提供键盘可访问的**跳过动画**入口（`Esc` / `Enter`），不必等待动画播完 |

### 5.3 焦点可见性（投影硬指标）

```css
:focus-visible {
  outline: 3px solid var(--c-accent);   /* 3 px 是硬指标：2 px 在 6 m 外看不清 */
  outline-offset: 2px;
  border-radius: inherit;
}
```

| # | 规则 |
|---|---|
| D8 | 焦点环 **3 px 实线 `--c-accent`，外偏移 2 px**，圆角跟随元素 |
| D9 | **禁止 `outline: none` 而不提供替代焦点样式** |
| D10 | 焦点环必须同时满足**形状变化**（3 px 实线环绕），不依赖颜色变化——色觉障碍者同样能识别 |
| D11 | 在两种主题 + 高对比主题下焦点环对比度均 ≥ 3:1（对相邻色） |

### 5.4 屏幕阅读器策略

| # | 规则 | 理由 |
|---|---|---|
| E1 | **实时数值不做 `aria-live`** | 每秒变化数十次会造成听觉灾难。改为快捷键 `V` **按需朗读**当前高度/速度/阶段/推进剂 |
| E2 | 仅对**离散事件**做 `aria-live="polite"`：阶段变化、分离事件、告警/危险触发、成就解锁、入轨成功 | 事件级播报有信息价值 |
| E3 | 播报**节流 ≥ 2 s**（同类事件 2 s 内只播报一次）；告警/危险可打断优先播报 | 防止连续事件刷屏 |
| E4 | 所有 SVG 图形：`role="img"` + `aria-label`；纯装饰图形 `aria-hidden="true"` | — |
| E5 | **Canvas 完全不可访问** → 提供等效的**文字状态面板**（默认折叠，可展开），供 SR 用户读取当前高度/速度/阶段/姿态/推进剂/轨道根数 | 这是 L0–L2 层（全部为 Canvas）的等效替代 |
| E6 | 讲解浮层 `role="region"` + `aria-live="polite"`，但**仅在新卡片出现时播报一次**，节流 ≥2 s | 避免逐字播报 |
| E7 | 事件时间线用 `role="list"` + `role="listitem"`，每个节点含完整文字（事件名 + 时刻 + 完成状态） | 键盘可遍历、SR 可读 |

## 6. 验收清单

实现完成后按此表逐项自检。**任一项不通过即为未达标。**

### 6.1 色彩与对比度

- [ ] 所有颜色通过主题变量引用，代码中无裸 hex
- [ ] 正文/数据文字标称对比度 ≥ 7:1（浅色与深色主题各测一遍）
- [ ] 可辨识边框对比度 ≥ 3:1
- [ ] ≤3:1 的组合仅用于装饰，未承载信息
- [ ] 高对比主题（H）可正常切换且全部界面可用

### 6.2 色盲友好

- [ ] 语义状态全部带形状编码（圆 / 三角 / 菱形 / 八角）
- [ ] 语义图标尺寸按严重度递增（24 / 28 / 32 / 36 px）
- [ ] 语义状态全部带常驻文字标签
- [ ] **纯 `color:` 变色的状态类（如 `.is-ok` / `.is-neg`）必须补第二重编码**——字重、图标或文字标签任一。仅改 `color` 而两者都是粗体（如 `<b>` 内）时，字重不构成区分，判为不达标
- [ ] 告警横幅（`.hud-alert`）类元素必须带形状图标，不能只靠边框颜色
- [ ] Deuteranopia / Protanopia / Tritanopia / Achromatopsia 四滤镜下逐一截图通过
- [ ] 图表多序列同时使用线型区分
- [ ] 量条分段同时有刻度线与阈值文字

### 6.3 大屏可读

- [ ] 中文最小 20 px，数字/单位最小 18 px（缩放后仍满足）
- [ ] 无 200/300 字重
- [ ] 中文正文行高 1.7
- [ ] 所有数字启用 `tabular-nums` 与等宽字体
- [ ] 同屏数据组 ≤ 7，每组 ≤ 3 个数值
- [ ] 讲解浮层 ≤ 3 行正文
- [ ] UI 缩放 100/125/150% 三档均不破版
- [ ] 最小可点击区 ≥ 48×48 px

### 6.4 动效

- [ ] `prefers-reduced-motion: reduce` 能自动进入精简档
- [ ] 三档动效开关（M）均生效
- [ ] 无 > 3 Hz 闪烁
- [ ] 无 > 25% 屏幕面积的高对比闪烁
- [ ] 无全屏旋转/缩放/视差抖动；相机缩放率 ≤0.5×/s、平移 ≤30% 屏宽/s
- [ ] 屏幕震动仅 1 次、≤150 ms、≤2% 幅度
- [ ] HUD 数值刷新率 ≤ 10 Hz，且为 tween 而非硬跳
- [ ] 粒子数随帧率自适应降级

### 6.5 键盘与焦点

- [ ] Tab 序列仅含可交互元素（HUD 数值不可聚焦）
- [ ] 焦点环 3 px 实线，两种主题 + 高对比主题下均 ≥3:1
- [ ] 无 `outline: none` 无替代的情况
- [ ] 浮层有焦点陷阱，Esc 可退出并恢复焦点
- [ ] 焦点顺序符合视觉顺序
- [ ] 快捷键表（5.1）全部实现且不冲突
- [ ] 可用键盘完成：点火 → 节流 → 分级 → 暂停 → 复位 的完整流程

### 6.6 屏幕阅读器

- [ ] 实时数值未接入 `aria-live`
- [ ] 离散事件播报正常，节流 ≥2 s
- [ ] `V` 键按需朗读 HUD 数值可用
- [ ] Canvas 等效文字状态面板可展开且内容完整
- [ ] 所有 SVG 有 `role` + `aria-label` 或 `aria-hidden`
